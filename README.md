# V-Shield 🚗

## 📌 Overview

V-Shield is a vehicle safety and alert system designed to detect nearby vehicles and provide real-time visual and audio warnings.

The project uses Arduino and ESP32 along with multiple sensors to monitor the surroundings of a vehicle.

## 🚗 Features

- Vehicle detection using IR sensors
- Distance measurement using HC-SR04 ultrasonic sensors
- OLED display for distance information
- LED-based warning system
- Buzzer-based proximity alerts
- Temperature and humidity monitoring using DHT11
- Motion and inclination monitoring using MPU6050
- ESP32-based web monitoring interface

## ⚙️ Working

The sensors continuously monitor the surroundings of the vehicle.

When a nearby vehicle or obstacle is detected, the system determines its position and distance and provides an appropriate warning using LEDs, a buzzer and displays.

The ESP32 can also provide sensor information through a web interface.
